# Aula IS–LM · edición para alumnos

Conceptualización y dirección: Profesor Pável Gómez Valera.

Entrada web: https://pavelgomez.github.io/ISLM-Aula-interactiva/

Este repositorio contiene exclusivamente la edición de distribución: portada, aula, medios, PDF, guion y créditos. No contiene credenciales, pesos de modelos, archivos de producción ni información de alumnos. No se declara una licencia abierta adicional a los derechos de los materiales y créditos correspondientes.

Para estudiar, abre index.html y pulsa «Abrir el aula interactiva». Si descargaste el paquete, extrae todos los archivos y conserva la carpeta ISLM_Aula_medios junto al HTML y al MP3. La apertura directa de archivos depende del navegador/dispositivo; el enlace web es la vía principal de distribución.

En un alojamiento estático, publica esta carpeta completa. No requiere instalar dependencias, ejecutar servidores de aplicación, usar claves de API ni iniciar sesión en ChatGPT. Las comprobaciones de carga son opcionales. La aplicación no guarda avance ni calificaciones. Los registros del proveedor de alojamiento se rigen por sus propias políticas.

La integración futura en MacroLab puede hacerse con un enlace o una ventana iframe. La integración no está instalada en MacroLab en esta entrega.

Créditos completos: ISLM_Creditos.md. Voz sintética: Kokoro-82M, em_alex, español; herramientas y fuentes en el archivo de créditos.
